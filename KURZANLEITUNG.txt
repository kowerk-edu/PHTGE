MATERIAL HOCHLADEN

1. Auf GitHub den Ordner "materialien" öffnen.
2. Thema und Unterthema öffnen.
3. Add file -> Upload files.
4. Datei hochladen und Commit changes drücken.

PDF / Bild / Video:
Direkt in den passenden Unterthemenordner laden.

Einzelne HTML-Übung:
Direkt als .html-Datei in den Unterthemenordner laden.

Simulation mit mehreren Dateien:
Einen eigenen Ordner anlegen. Die Startdatei muss index.html heißen.
CSS, JavaScript, Bilder und andere Hilfsdateien bleiben in diesem Ordner.
Auf der Kursseite erscheint nur die Simulation.

Material entfernen:
Datei oder Simulationsordner auf GitHub löschen und committen.
Der Eintrag verschwindet automatisch und es bleibt kein alter Dateilink zurück.

Externe Links:
Eine links.json nach dem Muster unter vorlagen/links.json verwenden.
Einen nicht mehr funktionierenden Link aus links.json löschen.
